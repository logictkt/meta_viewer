# Meta Viewer

SEO メタ情報を確認するための 2 つの配布形態を管理するリポジトリです。

- [Rails gem](gem/README.md): development 環境を既定として、Rails ページ上にメタチェックパネルを追加します。
- [Chrome Extension](chrome-extension/README.md): ツールバーの拡張機能ボタンから、現在のページのメタ情報を popup に表示します。

どちらも title、description、robots、canonical、Open Graph、X (Twitter) Card、ソーシャル画像、見出し構造を確認できます。
